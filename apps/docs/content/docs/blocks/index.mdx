Blocks are full documents — not single components. Each block renders a complete `<Document>` from typed data, so you can pass it straight to `PDFViewer` or `renderToBuffer`.

Like [registry components](/docs/registry), blocks are installed with the shadcn CLI: the source is copied into `components/pdf/` along with the components it uses, and you own the code.

```bash
npx shadcn add https://ui-registry.com/r/pdf/invoice.json
```

## Available blocks

| Block | Description |
|-------|-------------|
| [Invoice](/docs/blocks/invoice) | Multi-page invoice with line items, taxes, totals and localized amounts |

## Conventions

Every block follows the same rules:

- **Typed data in, document out**: content comes from a `data` prop, nothing is hard-coded.
- **Themeable**: only semantic colors are used; pass a `theme` prop to match your brand.
- **Translatable**: visible labels can be overridden with a `labels` prop.
- **Multi-page safe**: headers and footers repeat, rows and summary sections never split across pages.
